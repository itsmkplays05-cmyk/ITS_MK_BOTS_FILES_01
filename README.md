# AFK Bot + Web Panel (Railway)

## Deploy
1. Push this folder to a GitHub repo.
2. Railway → New Project → Deploy from GitHub repo.
3. Variables tab: set `PANEL_PASSWORD` (required for safety). Optional: `MC_HOST`, `MC_PORT`, `MC_VERSION`, `BOT_USERNAME`.
4. Settings → Networking → Generate Domain → open it for the panel.

Edit `settings.json` for chat messages / anti-afk etc.
